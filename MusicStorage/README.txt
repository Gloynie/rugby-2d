PIXELRUGGAS – MUSIC FOLDER
==========================

Drop your .mp3 files in this folder and the game plays them as background music.

  • Name them like  "Song Title - Artist.mp3"  (e.g. "Rocketeer - Far East Movement.mp3").
    Any filename that contains the song title is recognised automatically.
  • Supported: mp3, m4a, aac, ogg, wav, flac, opus.
  • If the game is already running just refresh the page – new files are picked up
    straight away (no restart needed when running locally).
  • The list of known song names lives in  src/game/music/playlist.ts
    – add your own entries there if you want proper titles for new songs.

No audio files are bundled with the game – add your own copies here.
You can also add songs from inside the game: Main menu → Music → "Add MP3 files".
